# CSS Animation Playground 🎨

A simple **HTML & CSS animation playground** created to practice and demonstrate different CSS animation techniques.

The project contains multiple animated shapes, each showcasing a different animation effect such as color changing, movement, rotation, pulsing, fading, spinning, wave motion, and border movement.

## ✨ Features

* 🎨 **Color Animation** — uses the `color` keyframes animation
* ↕️ **Move Animation** — uses the `move` keyframes animation
* 🔄 **Rotate Animation** — uses the `rotate` keyframes animation
* 💓 **Pulse Animation** — uses the `pulse` keyframes animation
* 🌫️ **Fade Animation** — uses the `fade` keyframes animation
* 🌀 **Spin Animation** — uses the `spin` keyframes animation
* 🌊 **Wave Animation** — uses the `wave` keyframes animation
* ⬜ **Border Movement** — uses the `move-border` keyframes animation

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS `@keyframes`
* CSS `transform`
* CSS animations

## 🎯 Animations Demonstrated

The project uses CSS `@keyframes` to create different animations:

```css
@keyframes color
@keyframes move
@keyframes rotate
@keyframes pulse
@keyframes fade
@keyframes spin
@keyframes wave
@keyframes move-border
```
